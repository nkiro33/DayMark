# DayMark

DayMark is a friendly daily productivity tracker for logging activities, habits, sleep, and weekly progress without guilt.

The app is designed to help users quickly record what happened during their day, understand their progress, and manage the activities they care about.

## MVP Scope

The first version focuses on:

- App shell
- Core activity models
- Daily screen structure
- Activities screen structure
- Settings screen structure

## Core Idea

DayMark uses a generic activity system instead of separate models for work, study, habits, and bad habits.

Main concepts:

- ActivityTemplate: what can be tracked
- ActivitySchedule: when it should appear
- CreditRule: how credits are calculated
- DailyActivityLog: what happened on a specific day
- DailyCheckIn: simple daily context, such as sleep
- WeeklySummary: weekly performance overview
- WeeklyReflection: explanation for unusual weekly changes
